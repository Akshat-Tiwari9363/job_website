# Job Website

A full-stack Job Management web application built using **React, Spring Boot, and MongoDB**. The application allows users to create, view, and search job postings based on profiles, skills, and keywords.

## 🚀 Tech Stack

### Frontend
- React.js
- React Router DOM
- Axios
- Material UI
- CSS

### Backend
- Java
- Spring Boot
- Spring Web
- Spring Data MongoDB
- Lombok
- REST APIs
- Swagger / OpenAPI

### Database
- MongoDB
